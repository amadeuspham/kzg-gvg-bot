Setup

Set up in three steps

About two minutes.

  1. Download and installRun the file. Your computer will show a warning the first time; see the box below, it is expected.
  2. Sign in with DiscordOpen the app and press Sign in with Discord. If that fails, type /connect in your server and paste the code.
  3. Hold a key and talkJoin your team voice channel. Hold the broadcast key you chose in the app and talk. Let go to stop.
Heads up

Your computer will warn you. That is normal.

This app is not signed by Microsoft or Apple yet, so Windows says “Windows protected your PC” and macOS says it cannot verify the file. It does not mean the file is damaged.

Windows: choose More info, then Run anyway. Mac: choose Done, then open System Settings, Privacy & Security and press Open Anyway.

Only install a file you got from this page or from the person who runs your server. Check the file yourself if you like.

Keys

Three ways to talk

You choose the key for each one in the app. Pick whatever suits your game.

Team key

Your team. Hold it to talk to your whole big team.

All-teams key

All teams. Hold it to talk to Attack and Defense together.

Open-mic key

Open mic. Press once and your team keeps hearing you until you press it again.

Phone players do not need the app. They hear broadcasts and talk in their own team channel as usual.

FAQ

Questions

What does the app see or do?

It listens for the keys you set so it knows when to broadcast, and sends that signal to your server's bot. It never types or clicks for you.

  • Windows: no special permission is needed.
  • Mac: it asks for Input Monitoring only, not Accessibility.
How do I check the file is genuine?

Compare its fingerprint with the matching line in the SHA256SUMS file on the release.

  • Windows: in PowerShell, run:
Get-FileHash .\DiscordBroadcast-win-x64-Setup.exe -Algorithm SHA256
  • Mac: in Terminal, run:
shasum -a 256 ~/Downloads/DiscordBroadcast-macOS-arm64-Setup.pkg

If the numbers differ, delete the file and download again.

Which Mac do I have?

Apple menu, About This Mac. A chip named M1 or newer means Apple chip, and the Mac download works for you. Intel Macs are not supported yet.

My keys do nothing in the game
  • Windows: a game running as administrator can hide key presses. The app says so and offers Restart as administrator.
  • Mac: in the app's Settings, open Input Monitoring settings and switch Discord Broadcast on.
Mac says the app is damaged

Remove the quarantine mark, then open it again:

xattr -dr com.apple.quarantine "/Applications/Discord Broadcast.app"
Windows has no Run anyway button

Right-click the file, choose Properties, tick Unblock, then OK and run it again.

How do I uninstall it?
  • Windows: Settings, Apps, Installed apps, Discord Broadcast, Uninstall.
  • Mac: drag Discord Broadcast from Applications to the Bin.
Do I get updates?

Yes. The app updates itself and shows Restart to update when ready.
